# BassamAI Lab — صفحة البداية

صفحة عربية باتجاه RTL لهوية مختبر بسام، مبنية بملف `index.html` مع صورتين حقيقيتين من واجهتي المشروعين المنشورين.

## محتويات الحزمة

- `index.html` — الصفحة الرئيسية وتنسيقاتها وتفاعلاتها.
- `assets/fursan-preview.webp` — لقطة شاشة من منصة فرسان الحساب.
- `assets/dinner-preview.webp` — لقطة شاشة من دليل العشاء المنزلي الذكي.

## التشغيل محليًا

افتح `index.html` في متصفح حديث. يلزم إبقاء مجلد `assets` بجانب الملف حتى تظهر صور المشاريع.

## النشر

ارفع الملفات مع الحفاظ على البنية التالية في جذر المستودع:

```text
BassamAiLab/
├── index.html
├── README.md
└── assets/
    ├── fursan-preview.webp
    └── dinner-preview.webp
```

على خادم الويب، يجب نسخ `index.html` ومجلد `assets` معًا إلى الإصدار الجديد. لا تنشر ملف HTML وحده؛ الصور مطلوبة لبطاقات المشاريع.

## ملاحظات

- الصور مأخوذة من لقطات شاشة قدّمها صاحب المشروع، وحُوّلت إلى WebP لتقليل حجم التنزيل.
- روابط المشاريع تشير إلى `fursan.bassamailab.xyz` و`dinner.bassamailab.xyz`.
- أزرار تصفية المشاريع والتنقل الداخلي وقائمة الهاتف تعمل ضمن الصفحة.
