# BassamAI Lab — صفحة البداية

صفحة عربية RTL مستقلة، مبنية في ملف `index.html` واحد. لا تعتمد على مكتبات JavaScript خارجية. خط Tajawal يُحمَّل من Google Fonts مع بدائل نظامية عند تعذّر الاتصال.

## التشغيل محليًا

افتح `index.html` في متصفح حديث.

## النشر

ارفع `index.html` إلى مجلد الموقع الذي يخدم النطاق `bassamailab.xyz`، بعد أخذ نسخة احتياطية من الملفات الموجودة. لا تغيّر إعدادات DNS أو إعدادات الاستضافة لمجرد نشر هذه الصفحة، ولا تستبدل مجلدًا يحتوي تطبيقات أخرى.

## ملاحظات

- روابط المشاريع تشير إلى النطاقين الحاليين: `fursan.bassamailab.xyz` و`dinner.bassamailab.xyz`.
- الرسوم داخل بطاقات المشاريع توضيحية ومصممة داخل الصفحة، وليست لقطات شاشة من التطبيقات الحية.
- أزرار التصفية، وقائمة الهاتف، وروابط التنقل تعمل ضمن الصفحة.
